# SMYGN32

## V2V-Enabled Collision and Trajectory Risk Assessment for Safe Mine Vehicle Operation

**Smart India Hackathon 2026 — SIH26007**

### Problem Statement

Safe and Efficient Operation of Mine Vehicles in Fog and Low-Visibility Conditions in Open Cast Iron Ore Mines.

During severe monsoon conditions, visibility in open-cast iron ore mines can reduce significantly, increasing the risk of collisions between heavy mine vehicles and forcing vehicles to slow down or stop.

### Our Solution

SMYGN32 is a predictive mine-vehicle safety system that combines multi-sensor perception, Vehicle-to-Vehicle (V2V) communication, trajectory prediction and Time-to-Collision (TTC) based risk assessment.

The system allows vehicles to share information about their position, speed, heading and vehicle state while combining this information with local sensor data.

### Core Concept

**Sense → Share → Fuse → Predict → Assess → Warn**

### Project Components

- Physical two-vehicle prototype
- Digital simulation
- V2V communication
- Sensor fusion
- Trajectory prediction
- Time-to-Collision (TTC)
- Collision-risk assessment
- Driver safety alerts
- Mine control-center visualization

### Repository

This repository contains the development, simulation, hardware prototype, documentation and presentation material for SMYGN32.

### Project Status

SMYGN32 is currently a scaled proof-of-concept developed for Smart India Hackathon 2026.

Production deployment would require industrial-grade sensors, communication systems, computing hardware and vehicle safety interfaces.
